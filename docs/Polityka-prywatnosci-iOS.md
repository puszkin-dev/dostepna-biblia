# Polityka prywatności dla iOS

[Publiczna polityka aplikacji „dostępna biblia”](https://axelek.pl/dostepna-biblia-prywatnosc.html) · [Treść źródłowa HTML](../www/dostepna-biblia-prywatnosc.html)

Wiążącą treścią serwowaną użytkownikom jest polska strona HTML, nie dawniejszy szkic w tym pliku. Obejmuje źródło czytań, przesyłanie fraz i adresów żądań, lokalne ustawienia, mowę, eksport plików, zewnętrzne odnośniki, kontakt i możliwość żądania usunięcia danych. Nie stanowi potwierdzenia praktyk przechowywania danych przez operatora TwojaBiblia.pl ani ukończenia ankiety App Privacy. [Weryfikacja i otwarte zagadnienia](Formularze-Apple.md).
